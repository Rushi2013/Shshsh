Roz ka kaam — 6 simple steps

Daily working routine

  1. Termux kholo → cd ~/uwin-smart-assistant → bash start.sh
  2. Chrome kholo → {{ url }} (ya termux-open-url {{ url }})
  3. Upload Excel → apni file chuno → preview dekho → column mapping check karo.
  4. Import & check dabao → har row validate + match ho jayegi (mobile par hi).
  5. Review Queue → ek-ek beneficiary dekho → Approve / Edit / Reject / Skip.
  6. Portal par confirm → reference number paste karo → record COMPLETED ban jayega.

Kaam khatam hone par bash stop.sh chala do. Data safe rahega, agli baar "Resume previous session" se wahi se shuru kar sakte ho.

Status ka matlab

Kya matlab hai har badge ka

  • PENDING — row padh li, problem nahi mili, abhi aapne faisla nahi kiya.
  • MATCHED — authorised register me pakka match mila (ID ya naam+DOB).
  • NEEDS REVIEW — kuch missing/conflicting hai, ya match pakka nahi hai. Aapko dekhna hai.
  • APPROVED — aapne sahi bola, portal par save karna baaki hai.
  • COMPLETED — portal ne confirm kar diya (reference number ke saath).
  • SKIPPED — abhi chhod diya, baad me khol sakte ho.
  • FAILED — reject kiya ya processing fail hui.
  • SAVE STATUS UNKNOWN — portal ne confirm nahi kiya. Portal par khud jaake check karo. Dobara automatic nahi bhejega.

Troubleshooting — problem aur solution

Sabse common problems

Chrome me dashboard nahi khul raha
  • Termux me server chal raha hai kya? Wahan Running on http://127.0.0.1:5000 dikhna chahiye.
  • Chrome me exactly likho: {{ url }} (http:// lagana zaroori hai).
  • Termux band ho gaya to dubara: bash start.sh
  • Port vyast hai to: UWIN_PORT=5001 bash start.sh aur Chrome me http://127.0.0.1:5001
“Module not found: flask / pandas”
  • pip install --upgrade pip
  • pip install -r requirements.txt
  • Phir check karo: python app.py --check
File upload nahi ho rahi / “not a real Excel file”
  • File ko Excel me kholo → Save As → Excel Workbook (.xlsx) → phir upload karo.
  • .csv bhi chalega (Upload page par accept hota hai).
  • File 5 MB se badi hai? Settings → Upload size limit badha do (max 25 MB).
“Missing columns” ya galat data import ho gaya
  • Upload page par Map Excel columns section kholo aur sahi column chuno.
  • Header row galat lag rahi hai? “Header row number” badal ke Reload preview dabao.
  • Data dobara import karna ho to: Records → file kholo → Import again (review decisions hat jayenge, warning milega).
Match nahi mil raha
  • Dashboard par Authorised beneficiary register import karo (naam/ID ki list).
  • Naam ki spelling alag hai to fuzzy suggestion milega — usse auto-approve mat karo.
  • DOB ka format galat ho to Settings → Date format set karo.
OTP page par aa gaya, ab kya?
  • OTP SMS me aata hai — usko official U-WIN page me khud type karo.
  • App SMS nahi padhta, OTP save nahi karta. Ye jaan-boojh kar aisa banaya gaya hai.
  • Login ho gaya to dashboard me “I am logged in — continue” dabao aur Excel kaam shuru karo.
Portal ne save confirm nahi kiya (SAVE STATUS UNKNOWN)
  • Portal khud kholo, beneficiary search karo, dekho dose pehle se hai ya nahi.
  • Agar pehle se hai → record ko us reference ke saath “I confirmed it on the portal” se complete karo.
  • Agar nahi hai → record kholo, dobara verify karke save karo. Automatic retry khatarnak hai (duplicate ban sakta hai), isliye app dobara nahi bhejta.
Phone restart ho gaya — mera kaam gaya?
  • Nahi. Sab kuch SQLite me save hota hai.
  • Dashboard kholo → Resume previous session dabao → wahi se aage badho.
  • Jo save confirm nahi hua tha wo “Save unknown” me dikhega — usko khud check karo.
App dheema lag raha hai
  • Settings → Rows per page kam kar do (10-20 rakho).
  • Bade file ko 2-3 hisson me todo, ya sirf zaroori rows rakho.
  • History → Cleanup now chala kar purani files hata do.
Data delete karna hai
  • Settings → Privacy → Delete ALL local data (confirm me DELETE likhna padta hai).
  • Sirf ek file ka data hatana ho to History → file ke saamne Delete dabao.

Important safety note

Padh lena zaroori hai

  • Ye app sirf data organise aur review karta hai. Final entry official U-WIN portal par aap khud karte ho.
  • Bina portal ke confirmation ke app kabhi “COMPLETED” nahi likhta.
  • App kisi bhi secret endpoint ko call nahi karta, OTP/CAPTCHA bypass nahi karta, rate limit nahi todta.
  • Patient ka data sirf authorised kaam ke liye use karo, aur kaam khatam hone par delete kar do.
  • Kisi ko apna U-WIN password ya OTP na batao — app bhi kabhi nahi maangta (form optional hai).
